# WPS Word 批量生成自动化宏

WPS 表格 + WPS 文字批量生成工具，使用 **WPS JS 宏（JSA）**。当前收录 **最终版 7.0 单窗弹窗版**。

> 本仓库是原 `cross-app-translator-and-office-macros` 单仓库拆分后的独立 Word 宏仓库；单仓库入口仍保留在 [xiaohaike/cross-app-translator-and-office-macros](https://github.com/xiaohaike/cross-app-translator-and-office-macros)。

## 文件

- `word自动化函数（最终版7.0-单窗弹窗版）.js`：主宏
- `用户窗体搭建说明.md`：7.0 用户窗体控件顺序、事件绑定与回退说明

## 环境

- WPS Office（较新版本）
- WPS 表格 + WPS 文字
- 使用 WPS「开发工具 → JS 宏 / 宏编辑器（JSA）」，**不是 Microsoft Office VBA**

## 使用步骤

1. 在 WPS 表格中准备数据，选中**只含数据行**的区域（不要选表头；每一行都会生成一份结果）。
2. 打开「开发工具 → JS 宏 / 宏编辑器」，新建模块。
3. 粘贴 `word自动化函数（最终版7.0-单窗弹窗版）.js` 全文，保存。
4. 可选：按 `用户窗体搭建说明.md` 创建「参数设置窗」用户窗体。
   - 没有用户窗体也能用：脚本会自动回退到逐项弹窗。
5. 运行宏 **`模板自动化word函数`**。
6. 选择 Word 模板 `.docx`，按 4 个开关设置：
   - 是否启用嵌套文件夹
   - 是否批量生成 Word
   - 是否批量生成 PDF
   - 是否把表格中的图片另存到输出目录
7. 结果默认输出到桌面：`批量生成word_创建时间_.../`。

## 模板占位符

- 文本占位符：`<1>`、`<2>`…… 对应选中区域第 1、2…… 个可见列。
- 图片占位符：模板浮动形状里写 `{3}` 这类文本；表格第 3 列单元格需有含 `ID_` 的图片名，脚本会保存并插入对应图片。
- 文件名/文件夹名支持 `<n>`，例如 `员工_<1>`。
- 图片需要是表格里的浮动图片，且名称含 `ID_`。

## 注意事项

- 选区不要包含表头；每一行都会生成一份文件。
- 占位符编号按**可见列**计算，隐藏列不计入。
- 运行前备份原始表格和模板；WPS 批处理较慢时请减少单次行数。
- 生成文件默认写到桌面；OneDrive/中文路径/权限异常时请先小数据试跑。
- 本脚本未在 Microsoft Office 中验证，不保证兼容 VBA。
